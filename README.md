# Hendrik Schoeman — Executive Bio Site

A fast, static personal site positioning Hendrik Schoeman for data center construction executive searches.

## Local preview

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Publishing target

The production URLs in the metadata, sitemap, and robots file currently target:

`https://hasdnf.github.io/data-center-executive/`

If the repository or domain changes, update those absolute URLs before publishing.
